# Fullstack AI Engineer

AI engineer with 7+ years of fullstack experience in TypeScript, Node.js, React, Java and Python. Based in Prague (CET). I build multi-agent LLM systems with MCP, model routing and evaluation on golden sets, and I bring AI into the way a team writes, reviews and ships code.

**Open to new roles:** remote, or hybrid in the EU. Available immediately.

## What I have built

- **AI agents in daily work.** Agents for code review, research and analysis, connected to the development environment through MCP. Typical task turnaround went down by 30%+, and the output stayed in line with the existing architecture.
- **AI code review.** AI reviewer agents and a new review flow for the team, once AI-generated pull requests grew past what people could review by hand. Time to first review went down by 50%+.
- **Cheaper agents.** Orchestration with a mix of models, subagents, RAG on LangGraph and pgvector, hooks, plain scripts and context engineering. AI cost and token usage went down by 35%+.
- **Evals on a golden set.** 200 cases of expected input and output for turning a user's search request into structured parameters. I used it to compare prompts and model combinations, local LLMs and Azure AI, and to pick the cheapest setup with the best results.
- **Products, end to end.** A production crypto information site built from zero on Node.js, React and Supabase. A full Shopify integration that replaced manual product entry. Database work that cut API requests per operation from 100+ to 10 to 20.
- **Backend services.** Kafka-based communication between microservices for fault tolerance and scale, and request optimisation that cut the cost per service by 15%.
- **People.** Mentored 4 new engineers through an AI-assisted review process and shared coding standards.
